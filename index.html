MAÎTRISE TOTALE

DEVENIR UN EXPERT EXCEL

Bienvenue dans le guide ultime pour dominer le tableur le plus puissant au monde. Ce tutoriel est conçu pour vous transformer de débutant à analyste de données pro.

1. L'Interface

Comprendre l'espace de travail est la première étape cruciale.

  • Le Ruban : Regroupe tous les outils (Accueil, Insertion, Formules).
  • Barre de Formule : C'est ici que la magie opère. Vous y tapez vos équations.
  • La Grille : Composée de colonnes (lettres) et de lignes (chiffres). L'intersection est une cellule (ex: A1).

2. Cellules & Saisie

Excel traite différents types de données :

  • Texte : Alignés à gauche par défaut.
  • Nombres : Alignés à droite. Attention au format (Monétaire, Pourcentage).
  • Dates : Excel les traite comme des nombres séquentiels pour permettre les calculs.
Astuce : Appuyez sur F2 pour modifier une cellule rapidement.

3. Formules de Base

Toute formule commence par le signe =.

=SOMME(A1:A10)

Additionne toutes les valeurs de la plage sélectionnée.

=MOYENNE(B1:B5)

Calcule la moyenne arithmétique.

4. Références $ (Le Secret)

Quand vous étirez une formule, Excel adapte les cellules. Pour "bloquer" une cellule, utilisez le symbole $.

  • A1 : Relatif (change partout).
  • $A$1 : Absolu (ne change jamais).
  • A$1 : Ligne bloquée uniquement.

5. Fonctions Logiques

La fonction SI permet de créer des conditions.

=SI(Moyenne>=10; "Admis"; "Recalé")

Si la condition est vraie, Excel affiche le premier texte, sinon le second.

6. Recherche de Données

Chercher une valeur dans un grand tableau.

=RECHERCHEV(Valeur_Cherchée; Table_Matrice; Index_Col; [Valeur_Proche])

Pro-tip : Utilisez RECHERCHEX si vous avez une version récente (Office 365), elle est bien plus puissante et simple !

7. Mise en Forme Conditionnelle

Faites parler vos données visuellement sans graphiques.

  • Barres de données : Pour visualiser l'ampleur d'un chiffre dans une cellule.
  • Nuances de couleurs : Idéal pour les cartes de chaleur (températures, ventes).
  • Règles personnalisées : "Si la valeur est > 100, mettre en rouge".

8. Tableaux Croisés Dynamiques

C'est l'outil ultime d'analyse. Il permet de synthétiser des milliers de lignes en quelques clics.

  1. Sélectionnez vos données.
  2. Insertion > Tableau Croisé Dynamique.
  3. Glissez les champs dans "Colonnes", "Lignes" ou "Valeurs".

9. Macros & Automatisation

Les macros permettent d'automatiser des tâches répétitives en enregistrant vos actions ou en écrivant du code.

A. Activer l'onglet Développeur

Par défaut, l'onglet est caché. Allez dans Fichier > Options > Personnaliser le ruban et cochez Développeur.

B. L'Enregistreur de Macros

C'est le moyen le plus simple : Excel "filme" ce que vous faites et le traduit en code. Idéal pour les débutants.

C. Introduction au VBA

Le VBA (Visual Basic for Applications) est le langage de programmation d'Excel.

Sub Bonjour()
  MsgBox "Bienvenue dans le monde de l'automatisation !"
End Sub

⚠️ IMPORTANT : Enregistrez toujours votre classeur au format .xlsm (Classeur prenant en charge les macros) sinon votre code sera perdu !
