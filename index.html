MAÎTRISE TOTALE

DEVENIR UN EXPERT EXCEL

Bienvenue dans le guide ultime pour dominer le tableur le plus puissant au monde. Ce tutoriel est conçu pour vous transformer de débutant à analyste de données pro.

1. L'Interface Avancée

Au-delà du simple ruban, Excel cache des outils de productivité puissants.

  • Le Ruban & Raccourcis : Personnalisez-le en faisant un clic droit. Utilisez ALT pour afficher les lettres de raccourci sur chaque onglet.
  • Barre d'Accès Rapide : Située tout en haut, elle permet d'épingler vos outils favoris (Enregistrer, Annuler, mais aussi "Aperçu avant impression").
  • Gestionnaire de Noms : (Onglet Formules) Permet de nommer une cellule ou une plage (ex: "TVA"). Au lieu de taper =A1*0,20, vous taperez =Prix*TVA.
  • Barre d'État : En bas à droite, elle calcule instantanément la moyenne, le nb et la somme des cellules sélectionnées sans aucune formule.

2. Maîtrise des Données & Formats

Excel ne "voit" pas ce que vous voyez. Il stocke des valeurs brutes et applique un masque de formatage.

A. Formats de Nombres Personnalisés

Utilisez le code [Rouge][<0]-0,00;0,00 pour afficher les nombres négatifs en rouge automatiquement.

B. Validation de Données

Empêchez les erreurs de saisie ! Allez dans Données > Validation des données pour créer des listes déroulantes ou restreindre la saisie à des dates précises.

C. Protection & Verrouillage

Par défaut, toutes les cellules sont "verrouillées", mais cela n'est effectif que si vous protégez la feuille (Révision > Protéger). Décochez "Verrouillée" dans le format de cellule pour les zones que l'utilisateur doit pouvoir modifier.

3. Formules & Calculs Statistiques

Les formules avancées permettent d'analyser des données sous condition.

=SOMME.SI.ENS(Plage_Somme; Plage_Critère1; Critère1; ...)

Additionne les valeurs si plusieurs conditions sont remplies (ex: Ventes de "Jean" en "Janvier").

=SIERREUR(Ma_Formule; "Texte si erreur")

Essentiel pour nettoyer vos tableaux et éviter les vilains #DIV/0! ou #N/A.

=NB.SI(A1:A100; ">10")

Compte le nombre de cellules qui répondent à un critère spécifique.

4. Références Dynamiques & Tableaux

Le secret des pros : Ctrl + L (ou Ctrl + T). Transformez vos données en "Tableau structuré".

  • Recopie automatique : Les formules s'étendent toutes seules aux nouvelles lignes.
  • Noms structurés : Au lieu de =A2*B2, vous aurez =[@Prix]*[@Quantité]. C'est bien plus lisible !
  • Ligne de totaux : Activez-la en un clic pour avoir des calculs instantanés en bas de tableau.

5. Logique Conditionnelle Complexe

Combinez le SI avec les fonctions ET et OU pour des tests multicritères.

=SI(ET(A1>=10; B1="Oui"); "Validé"; "En attente")

Le résultat est "Validé" uniquement si les DEUX conditions sont vraies.

=SI(OU(A1<0; A1>100); "Alerte"; "OK")

Affiche "Alerte" si la valeur est en dehors des bornes [0-100].

6. Recherche de Données (Le Trio Gagnant)

Il existe trois façons majeures de croiser des données :

  • RECHERCHEV : La base. Cherche à droite uniquement.
  • INDEX + EQUIV : L'alternative historique. Plus flexible (cherche à gauche) et plus rapide sur de très gros fichiers.
  • RECHERCHEX : Le nouveau standard (Office 365). Gère les erreurs, cherche vers le haut/bas/gauche et ne casse pas si vous insérez une colonne.
=INDEX(Plage_Retour; EQUIV(Valeur; Plage_Recherche; 0))

7. Mise en Forme Conditionnelle

Faites parler vos données visuellement sans graphiques.

  • Barres de données : Pour visualiser l'ampleur d'un chiffre dans une cellule.
  • Nuances de couleurs : Idéal pour les cartes de chaleur (températures, ventes).
  • Règles personnalisées : "Si la valeur est > 100, mettre en rouge".

8. Tableaux Croisés Dynamiques (Expert)

Ne vous contentez pas de glisser-déposer. Maîtrisez l'analyse.

  • Segments (Slicers) : Créez des boutons visuels pour filtrer vos TCD en un clic (onglet Analyse du TCD > Insérer un segment).
  • Paramètres des champs de valeurs : Changez "Somme" par "Moyenne", "Max" ou même "% du total général" pour une analyse relative.
  • Champs calculés : Ajoutez vos propres formules à l'intérieur du TCD sans modifier vos données sources.
  • Chronologie : Un segment spécial pour filtrer par périodes (années, mois, jours) de manière ultra-fluide.

9. Power Query : L'arme Secrète

Oubliez les macros complexes pour nettoyer vos données. Power Query (Données > Récupérer et transformer) permet d'automatiser le nettoyage.

  • Dépivoter les colonnes : Transformez un tableau croisé en une liste plate en un clic.
  • Fusionner des requêtes : L'équivalent surpuissant du RECHERCHEV pour lier deux tables.
  • Type de données : Forcez le formatage des colonnes dès l'importation pour éviter les erreurs de calcul plus tard.

10. Macros & VBA Professionnel

L'automatisation réelle passe par la compréhension du modèle d'objet Excel.

A. Le Modèle d'Objet

Excel est une hiérarchie : Application > Workbook > Worksheet > Range.

Worksheets("Fiche1").Range("A1").Value = "Terminé"

B. Les Événements

Vous pouvez déclencher du code automatiquement lors d'une action de l'utilisateur (ex: Ouverture du fichier, changement d'une cellule spécifique).

C. Les Variables

Déclarez toujours vos variables pour gagner en vitesse et éviter les bugs : Dim maValeur As Integer.
